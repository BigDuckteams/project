# Тихо

Android-приложение для локальной расшифровки разговоров: преобразует речь в текст, определяет говорящих и формирует реплики с временными метками. Аудио обрабатывается на устройстве через **sherpa-onnx 2.0.1**; интернет нужен только для первоначальной загрузки выбранных моделей.

## Возможности

- **GigaAM v3 E2E RNNT** по умолчанию для русской речи, пунктуации и нормализации.
- Каталог моделей: GigaAM v3/v2, Whisper Small/Base/Tiny, SenseVoice, Dolphin.
- Локальная диаризация Pyannote Segmentation 3.0 + 3D-Speaker.
- Импорт аудио/видео и запись с микрофона, пауза и фоновая запись.
- Автоматическое или заданное число участников.
- Структурированный диалог с участниками и временными метками.
- Поиск, фильтры по участникам, переименование и редактирование реплик.
- Плеер с переходом к реплике, экспорт TXT/JSON/SRT.
- Светлая и тёмная темы, немультяшный звуковой маскот.

## Сборка

Требования: JDK 17, Android SDK 36. В проект включён официальный `sherpa-onnx-2.0.1.aar` (SHA-256: `a8d09d1d32f3eb8520482c6d3d43fae674681c5b050385967c70a3c2c9bf0ee7`).

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск

1. Выберите модель в разделе «Модели» или используйте GigaAM v3 E2E.
2. Скачайте модель. При первой загрузке также устанавливаются файлы диаризации.
3. Выберите аудиофайл или запишите разговор.
4. Дождитесь локальной обработки. После установки моделей интернет не нужен.

Длительность записи ограничена 6 часами. Качество диаризации зависит от шума и перекрывающейся речи. Распознавание больших моделей на мобильном CPU может занимать заметное время.

## Структура

- `data` — каталог моделей, загрузки, настройки и локальное хранилище JSON.
- `audio` — системное декодирование и преобразование в 16 кГц моно.
- `recording` — foreground-сервис записи WAV.
- `processing` — GigaAM/Whisper, диаризация, сборка диалога и foreground-обработка.
- `export` — TXT/JSON/SRT.
- `ui` — Jetpack Compose, Material 3.

Минимальная версия Android: 8.0 (API 26).
